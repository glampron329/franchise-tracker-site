# Franchise Tracker — site hébergé

Pages publiées par GitHub Pages : https://glampron329.github.io/franchise-tracker-site/

Ce dépôt ne contient que le dossier `site/` généré par `python make_site.py --lite` dans le dépôt privé `franchise-tracker`.
Ne pas modifier ces fichiers à la main : ils sont remplacés à chaque livraison.
Aucune donnée de la franchise n'est dans ces fichiers ; elles viennent de Supabase après la connexion.
